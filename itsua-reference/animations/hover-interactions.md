## 1. The Harmonic Oscillation Formula

Itsua's most recognizable micro-interaction is the tactile physical wobble executed when hovering over any card in the Featured Work deck or Client Reviews. 

Rather than using an approximate CSS bezier curve (`ease-in-out` or `cubic-bezier`), the animation is generated by a trigonometric equation evaluating directly over performance timestamps:

$$\theta(t) = 15 \cdot \sin(\pi \cdot t) \cdot \sin(2\pi \cdot t) \quad \text{for } 0 < t < 1$$

Where:
- $t = \frac{\text{elapsedTime}}{\text{totalDuration}} = \frac{\text{performance.now()} - \text{startTime}}{900\text{ms}}$
- Peak amplitude: `15 degrees`
- Settling boundary: Exactly `0 degrees` at $t=0$ and $t=1$.

```javascript
// Extracted from deck.Cx960KMr.js:
const c = t => t <= 0 || t >= 1 ? 0 : 15 * Math.sin(Math.PI * t) * Math.sin(2 * Math.PI * t);
const h = 900; // Duration: 900 milliseconds
export { h as H, c as r };
```

## 2. Kinetic Curve Behavior Analysis

Plotting $\theta(t)$ from $t = 0.0$ to $t = 1.0$:

```text
Angle (deg)
 +15 |           /\
     |          /  \
     |         /    \
   0 +--------/------\----------/------+ t
     |                \        /
     |                 \      /
 -15 |                  \____/
     +---------------------------------+
     t=0.0      t=0.35   t=0.65       t=1.0
```

1. **Phase 1 ($t = 0.0 \to 0.35$):** Initial forward tilt reaching maximum positive deflection ($+15^\circ$) around $t \approx 0.25$.
2. **Phase 2 ($t = 0.35 \to 0.65$):** Spring recoil swinging through zero into negative deflection ($-15^\circ$) around $t \approx 0.75$.
3. **Phase 3 ($t = 0.65 \to 1.0$):** Decay and gentle return to rest ($0^\circ$).

## 3. 180° 3D Flip Interaction

When a user clicks on any card (unless clicking a CTA link `.deck-cta` inside the card), the card executes a full 180° perspective flip:

```javascript
// Extracted from ReviewCard.js:
card.addEventListener("click", e => {
  if (e.target.closest(".deck-cta")) return;
  isFlipped = !isFlipped;
  card.classList.add("by-pointer");
  tick();
});

const tick = () => {
  const elapsed = (performance.now() - startTime) / 900;
  const rotationAngle = isFlipped ? 180 : c(elapsed);
  card.style.setProperty("--rx", `${rotationAngle}deg`);
  card.classList.toggle("is-raised", isFlipped || isHovered || elapsed < 1);
  return elapsed < 1;
};
```

## 4. Complete Standalone Implementation Component (React / TypeScript)

```tsx
import React, { useState, useRef } from "react";

export function TactileCard({ frontContent, backContent }: { frontContent: React.ReactNode; backContent: React.ReactNode }) {
  const [isFlipped, setIsFlipped] = useState(false);
  const startTimeRef = useRef<number>(-Infinity);
  const animFrameRef = useRef<number | null>(null);
  const cardRef = useRef<HTMLDivElement>(null);

  // Exact Itsua wobble formula
  const wobble = (t: number) => {
    return t <= 0 || t >= 1 ? 0 : 15 * Math.sin(Math.PI * t) * Math.sin(2 * Math.PI * t);
  };

  const startWobble = () => {
    startTimeRef.current = performance.now();
    const animate = (now: number) => {
      const elapsed = (now - startTimeRef.current) / 900;
      if (cardRef.current) {
        if (!isFlipped) {
          const angle = wobble(elapsed);
          cardRef.current.style.setProperty("--rx", `${angle.toFixed(2)}deg`);
        }
      }
      if (elapsed < 1) {
        animFrameRef.current = requestAnimationFrame(animate);
      } else {
        if (cardRef.current && !isFlipped) {
          cardRef.current.style.setProperty("--rx", "0deg");
        }
      }
    };
    if (animFrameRef.current) cancelAnimationFrame(animFrameRef.current);
    animFrameRef.current = requestAnimationFrame(animate);
  };

  const handleClick = (e: React.MouseEvent) => {
    if ((e.target as HTMLElement).closest(".deck-cta")) return;
    setIsFlipped(!isFlipped);
  };

  return (
    <div
      ref={cardRef}
      onClick={handleClick}
      onPointerEnter={startWobble}
      style={{
        perspective: "1200px",
        transformStyle: "preserve-3d",
        transform: `rotateX(${isFlipped ? 180 : "var(--rx, 0deg)"})`,
        transition: isFlipped ? "transform 0.6s cubic-bezier(0.16, 1, 0.3, 1)" : "none",
      }}
      className="relative cursor-pointer rounded border border-line bg-white p-6 shadow-sm"
    >
      <div style={{ backfaceVisibility: "hidden" }}>{frontContent}</div>
      <div style={{ backfaceVisibility: "hidden", transform: "rotateX(180deg)" }} className="absolute inset-0 p-6">
        {backContent}
      </div>
    </div>
  );
}
```
